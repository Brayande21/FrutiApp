# FrutiApp

FrutiApp es un juego educativo para Android que desarrollé con el objetivo de ayudar a los niños a aprender y practicar matemáticas de una manera más divertida, utilizando frutas, imágenes y diferentes actividades.

Este fue uno de mis proyectos de programación, donde pude poner en práctica mis conocimientos de Java y desarrollo de aplicaciones móviles.

## ¿Cómo funciona?

El juego cuenta con 6 niveles, cada uno con diferentes actividades. Utiliza imágenes de frutas y otros elementos visuales para que los niños puedan interactuar con el juego mientras aprenden.

## Tecnologías utilizadas

- Java
- Android Studio
- XML para las interfaces
- SQLite
- Gradle

## Sobre el desarrollo

Para desarrollar FrutiApp trabajé con diferentes pantallas, manejo de eventos, imágenes y recursos multimedia.

También utilicé SQLite para trabajar con el almacenamiento de información dentro de la aplicación.

Este proyecto me ayudó a comprender mejor cómo se desarrolla una aplicación Android y cómo conectar las diferentes partes de un programa.
